# Troubleshooting

| Symptom                                                                         | Likely cause                                                                     | Fix                                                                                                                                                                                                                                |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm run dev`: client says "Could not reach the server"                         | Server isn't running or is on a different port                                   | Run `npm run dev` (starts both). The dev client expects `ws://<host>:8080/ws`; override with `VITE_WS_URL`.                                                                                                                        |
| Server exits immediately with "Configuration error"                             | Production env incomplete or a number out of range                               | Read the message: it names the variable. In production `ALLOWED_ORIGINS` is required and may not be `*`.                                                                                                                           |
| WebSocket closes at once / HTTP 403 on upgrade                                  | Origin not allowed (production)                                                  | Add the exact page origin (`https://host`, no trailing slash) to `ALLOWED_ORIGINS`.                                                                                                                                                |
| Works on `http://localhost`, fails when hosted over https with "mixed content"  | Client trying `ws://` from an `https://` page                                    | Use `wss://` (set `VITE_WS_URL=wss://…/ws`, or use single-host Option A).                                                                                                                                                          |
| First visit after a while takes ~a minute / "Could not reach the server"        | Free host spun the server down                                                   | Wait and press **Retry now**; the client already pings `/health` on load to wake it.                                                                                                                                               |
| Invite link `/join/CODE` shows 404 on a static host                             | Host doesn't rewrite unknown paths to `index.html`                               | Cloudflare Workers: already handled (`not_found_handling` in `wrangler.jsonc`). Netlify: add `/*  /index.html  200` as `client/dist/_redirects`. GitHub Pages: the generated `404.html`. Or serve the client from the game server. |
| "Room not found" for a valid-looking code                                       | Room expired (10 min idle lobby / 5 min results), server restarted, or typo      | Create a new room. Codes never contain I, L, O, 0, 1.                                                                                                                                                                              |
| "Match in progress" when joining                                                | Joining is allowed only in the lobby/results                                     | Wait for the match to end, or ask the host for a new room.                                                                                                                                                                         |
| Rate-limited / "too many requests" toasts                                       | Rapid repeated actions, or many failed joins from one IP                         | Wait a minute. Limits are per connection and per IP.                                                                                                                                                                               |
| My tank rubber-bands                                                            | High latency or packet loss; the server is authoritative and corrects prediction | Use a closer region; check `Settings → Show frame rate and ping`.                                                                                                                                                                  |
| Tank keeps moving after tab switch                                              | It shouldn't: inputs are neutralised on hide and after 1 s without input         | If it persists, report it with the browser and version.                                                                                                                                                                            |
| No sound                                                                        | Browsers block audio until a click/keypress; or Mute is on                       | Click once on the page; check Settings.                                                                                                                                                                                            |
| Touch joystick feels twitchy/sluggish                                           | Sensitivity                                                                      | Settings → Touch joystick sensitivity (50–150%).                                                                                                                                                                                   |
| Phone is in portrait                                                            | The battlefield is landscape                                                     | Rotate the phone, or tap "Continue anyway".                                                                                                                                                                                        |
| `npm run test:e2e` fails with "browser not found"                               | Chromium not installed                                                           | `npx playwright install chromium`.                                                                                                                                                                                                 |
| e2e: port 4173 in use                                                           | Another server running                                                           | Stop it or set `reuseExistingServer` accordingly (default reuses a running server outside CI).                                                                                                                                     |
| `npm run perf` says server/dist missing                                         | Not built                                                                        | `npm run build` first.                                                                                                                                                                                                             |
| Windows: `NODE_ENV=… cmd` syntax errors                                         | cmd.exe doesn't support inline env                                               | Use PowerShell (`$env:NODE_ENV='production'; node …`), WSL, or set env in the host dashboard. (Dev/test scripts were only run on Linux.)                                                                                           |
| Cloudflare build: `Invalid _redirects configuration ... Infinite loop detected` | A `_redirects` file with `/* /index.html 200` is in `client/public`              | Delete it; Workers already serves the app for unknown paths.                                                                                                                                                                       |
